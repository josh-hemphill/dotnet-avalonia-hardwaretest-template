# Workspace and form task layout (Area 3)

Area 3 is based on the reviewed library/device work at `bc132d232c4fcf71e97119957cadb9caa8612556`. It changes presentation and safe untouched-input suggestions, without changing the compiler, receipts, library discovery, runtime ownership, or shared operator widgets. ## Task layout

- Hardware opens with selected-program binding requirements, then a responsive instrument list/editor and scoped add/remove decisions. Program identity, DUT/operator requirements and lifecycle decisions follow as secondary settings.
- Definitions keeps each workspace catalog beside its add fields and distinguishes hardware template selection from selected-program membership.
- Environment leads with the selected home and truthful readiness. Requirements, preparation and archive import share a task group; runtime detail, recovery and declarations follow.
- Build leads with saved-plan inclusion, distinguishes compiled-only input from editable saved revisions, and places Pack directly after the save guard and home context. Previous receipts/history and package declarations retain separate sections.
- Issues distinguishes editing draft findings from saved-plan checks. Each row retains severity, code, scope and navigation; the empty saved-plan area describes absent rows without claiming a current check.
- Preview groups source provenance and session/recording actions above the unchanged operator board. Its containment calculations measure the added containers rather than guessing their heights.
- The step inspector groups configuration, recipe/pass decisions, display and advanced identity/history fields while retaining unknown values and focus commits.
- Workspace creation, new-plan and settings forms have a scrolling body and fixed decisions. Separate forms inherit owner text size. Guided entry says “First test plan” before task selection; explicit voltage recipes and completion wording remain. New library slots suggest INSTR1 only for untouched automatic input; intentional, reused and retained names remain exact.
