# Full-stack manual handoff checklist

This is preparation, not evidence of completed platform or engineer validation. Final handoff must identify the published top branch, exact head, application download/run command, fixture folder, recording dataset and build output locations. All packages06–22 remain separate PRs; none is merged automatically.

## Representative workflows

1. Create empty and product/demo workspaces; confirm chosen resources and package prerequisites. Cancel and collide with an existing destination; existing bytes must remain intact. Exercise failure/cancellation after publication and confirm only unchanged files created by this operation are removed; unrelated or externally changed files remain.
2. Use both guided and direct routes to create equivalent voltage-test documents. Leave guidance at each durable stage and resume without losing entered content. Follow missing-package/criterion recovery actions, and distinguish explicit demo instruments from product choices. Create a voltage acquisition and mean criterion with an explicitly selected instrument. Save an incomplete draft, close/reopen, complete it and verify stable selection/IDs.
3. Edit two plans, save one, cancel replacement, Undo/Redo nested changes, then recover unsaved work. In guidance, leave/resume an authored plan ID and numeric/incomplete acquisition interval, switch the average criterion on/off, and confirm unsupported interval input cannot disappear during creation. With two app instances, save/compile a changed threshold, instrument binding or display name in the second instance; the first must remain incomplete with its current edits/Undo intact until reopening or reconciling the matching saved content. Test future-schema/read-only and external compiled-file conflict states.
4. Change display independently of criteria; explore an unsupported formula, save it, and compare preview-only exclusion with a deployment blocker. Average a known scalar sibling: verify the example label and strict deployment blocker. Enter incomplete numeric text on native filter/average dependencies: findings and preview must agree with compilation.
5. Import a supplied recording, inspect provenance/time base, and compare values/verdicts with shared runtime semantics. Invalid/colliding imports preserve previous data and selection. Start in Example mode, explicitly select a recording, then switch back. Check disabled calculations and scalar→mean or mean→mean chains show honest unavailable/runtime capability issues. Replace an import source during copying and complete delayed pickers after workspace/program changes; prior selection and data must survive. Open an ordinary decompiled timed-publisher plan and compare typed/raw/mixed forms against the same recorded grid, including non-increasing publication order. Select separate repeated scopes with the same output name; values, diagnostics and evidence counts must stay with the selected node. Unknown/malformed raw steps feeding means or filters must leave the whole editor usable, including Issues and deployment status. Keep a selected recording through same-program refresh/reordering; switching programs/workspaces or deleting/replacing the selected run must return to Example. Raw publishers without recording samples must retain unavailable tiles. Inspect calculations directly after a nested repeat that is the first child of its outer repeat; each outer iteration must retain separate values and evidence. Inspect filter→filter and filter→mean chains; compare repeated executions separately rather than pooled means. Confirm acquisition and criterion tiles share the selected source and show example/recording labels, producer/run/iteration evidence, DUT and time-base availability.
6. Add and replace referenced hardware, inspect cross-program impact, and undo. Verify no implicit instrument substitution. Change selected OpenTAP home and confirm the visible package status refreshes. Clear the override and verify missing/present package metadata in the workspace default home is reported accurately. Edit/remove workspace hardware templates, ensuring existing program bindings remain unchanged; explicitly include into another program. Reuse two bindings with the same slot/type/address but different timeout/settings: labels must distinguish their origins and selecting the later binding must preserve its exact settings after save/reopen without changing the original.
7. Insert/duplicate/move/repeat steps; inspect internal/external references and rejected unsafe order changes. Include an imported Band Scalar with different presentation and actual metric names; new and duplicated outputs must avoid both aliases.
8. Navigate missing-threshold and plan-wide findings; edit or delete targets and verify stale findings behave honestly. Unsupported fields advertise settings fallback before clicking. Save sidecar after a clean or empty validation report and confirm captured-byte changes mark the check stale. Lock or make a checked source unreadable, then navigate: no target should open, the report becomes stale, an honest read error appears, and source bytes remain intact.
Before validating, externally replace the saved manifest with invalid/future-schema content; validation must refuse instead of using the cached manifest. Before saving, lock a checked input: SaveSidecar, Apply and SaveAll must refuse before publication and retain dirty content. Incomplete supported drafts must remain savable. SaveAll with an earlier duplicate-channel draft and a later valid draft; Validate must retain the earlier actionable compiler reason, then clear it after successful correction. If saved inputs become unreadable after publication, preserve the completed-save result and show the verification warning through preview refresh.
9. Prepare the selected offline environment, build saved content, and inspect included/excluded programs, real compatibility outcome, receipt revision/dependencies and outputs. Failure/cancellation preserves earlier successful artifacts. Before opening, corrupt or use a future schema in an excluded draft: included programs must still open and package, with excluded bytes preserved. A supported excluded draft with newer values remains editable; reinclusion exposes its blocker. An included source-only draft must require compilation before export. Delete the last measurement from single and nested repeats: an included empty loop must show a first-measurement issue and block Pack after save/reopen or explicit compilation. Undo/Redo and adding a real nested measurement must restore readiness correctly; exclusion and supported legacy compiled-only setup/cleanup remain usable. Remove a declared OpenTAP payload file and inspect the missing state; the checker must not run. Point a declared installed payload outside the selected home using a file or directory link: readiness and public preflight must reject it without invoking compatibility, and failed preparation must preserve the original home. Prepare an incomplete home with a different installed engine version: refusal must preserve its original runtime and metadata. Enter an invalid home path, save drafts, and confirm completed saves retain a separate preview warning and earlier receipt. Correct the home while an included or excluded uncompiled draft remains: the obsolete home warning must clear immediately without another save, while genuine compilation warnings remain. A home pointing at an existing file or below a file must be unavailable; a genuinely missing directory remains eligible for preparation. Exercise direct Pack with an explicit checked home that differs from the rendered preference: the receipt names the checked home and stays stale for the rendered home. Import two missing external packages one at a time; each complete import must publish while remaining prerequisites stay visible. A missing InstrumentComponents package must not prevent importing another package. Reject optional/undeclared archives with missing or unsafe payload, including archives that could otherwise borrow existing files. Exercise ordinary preparation through the app and CLI against incompatible required versions. Edit a draft while an actual packaging child is paused; completion must show the originally checked revision and stale readiness. Start another Pack immediately when the first operation becomes idle; an enabled action must open its picker and run even while the old handler continuation is completing.
10. Start slow work, cancel it, replace workspace, then close; UI remains responsive and owned descendants terminate.
11. Use palette and keyboard shortcuts with a text field focused; save/rename/duplicate/find issues without breaking normal text editing. Restore a layout on a smaller screen, collapse/reset the rail and Issues drawer, and confirm future preference bytes are preserved. Launch the TUI through its prerequisite checks, externally modify a plan, and reconcile on return without silently overwriting drafts. Complete delayed workspace/creation/recording pickers and pending Save All/Discard choices after the owner hides or the session changes; stale results must not mutate the replacement workspace.
